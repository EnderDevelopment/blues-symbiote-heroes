# Spider-Man 2 Mod

This Minecraft mod is inspired by Insomniac's Spider-Man 2, featuring a custom ArmorItem "Symbiote Black Suit" and a weapon "Symbiote Web Shoot". The mod includes visual overrides, player stats enhancements, integrated web wings for gliding, a symbiote surge mechanic, rope swinging, and a removal struggle mechanic. It is built using the NeoForge 1.21.1 API for both client and server.

## Install

1. Download the mod file from the GitHub repository.
2. Place the downloaded file in your Minecraft mods folder.
3. Launch Minecraft and select the NeoForge profile.

## Use

1. Equip the "Symbiote Black Suit" to override your body skin with a custom texture and gain permanent Attribute Modifiers: Strength III, Speed II, and Jump Boost II.
2. Use the "Symbiote Web Shoot" weapon to shoot web projectiles.
3. Press 'G' to trigger the Symbiote Surge, entering a 20-second rage state with aggressive texture, Resistance IV, Haste II, and +6 attack damage.
4. Swing on ropes by hitting blocks with web projectiles.
5. Press 'M' to attempt to rip off the Symbiote, holding for 80 ticks (4s) to freeze the player, spawn particles, and loop sound. On success, the suit is removed, dropped, and the player takes 8.0F damage.
